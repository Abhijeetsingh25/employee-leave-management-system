# employee-leave-management-system
A full-stack Employee Leave Management System with role-based authentication for Admin, HR, and Employees.

Frontend:
- React.js
- Material UI
- Redux Toolkit

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication

Features:
- Admin Dashboard
- HR Dashboard
- Employee Dashboard
- Role Based Access Control
- Leave Management
- Attendance Tracking
- Reports Export (Excel/PDF)
- Password Management
